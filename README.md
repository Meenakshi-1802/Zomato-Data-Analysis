# 🍽 Zomato Data Set Analysis

**Analyze restaurant data to uncover cuisine trends, city-wise ratings, and cost patterns using Python. Developed in VS Code.**

# Project Overview

This project analyzes the Zomato restaurant dataset to extract actionable insights about restaurants, cuisines, customer ratings, and pricing patterns. Using Python libraries like Pandas, Matplotlib, and Seaborn, the analysis provides data-driven insights to understand restaurant trends and customer preferences.

**Development Environment: Visual Studio Code (VS Code)**

# Key Features

- Cleaned and preprocessed raw restaurant data for accurate analysis

- Explored restaurant ratings, online ordering, and booking trends

- Visualized city-wise ratings, cuisine popularity, and cost patterns

- Provided insights to support data-driven business decisions

# Technologies Used

- Python – Programming language

- Pandas – Data manipulation and analysis

- Matplotlib & Seaborn – Data visualization

- Jupyter Notebook / VS Code – Interactive coding environment

# Dataset

- Information about restaurants in India, including:

- Restaurant name, location, and type

- Online ordering & table booking options

- Ratings, votes, and cuisine information

- Approximate cost for two people

# Visualizations

- Bar plots for restaurant types and cuisine popularity

- Box plots to analyze ratings vs. online order availability

- Scatter plots for cost vs. rating

- Top locations with most restaurants
